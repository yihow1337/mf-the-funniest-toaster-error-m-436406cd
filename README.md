One toaster error message, 54 characters, no puns: a toaster reporting the most ordinary fault it has — the lever that will not stay down — and then quietly asking its owner to confirm that it gave the job an honest attempt. The entry is a stdlib-only Python program that writes that single line to `entry.txt` in the output directory, byte-identical on every run. The line is kept in `entry.txt` beside the program, so the text is the only thing that ever needs editing.

## Run it
